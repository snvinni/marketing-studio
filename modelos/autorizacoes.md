# Autorizações de uso de imagem e depoimento

Toda foto ou vídeo de paciente, e todo depoimento de tutor, precisa de uma linha aqui antes de ser publicado.

## Mensagem para pedir autorização ao tutor

> Oi, {tutor}! Tudo bem? Tirei uma foto linda do(a) {pet} na visita de hoje. Posso usar no meu Instagram e no meu site? Não aparece seu nome, endereço nem nada da sua casa que identifique vocês. Se preferir que não, sem problema nenhum!

Guarde o print da resposta no Drive, na pasta `autorizacoes/`.

## Registro

| Data | Tutor (nome abreviado) | Pet | O que foi autorizado (foto, vídeo, depoimento) | Onde pode usar (Instagram, site, Google, anúncio) | Prova (arquivo no Drive) |
|---|---|---|---|---|---|
| | | | | | |

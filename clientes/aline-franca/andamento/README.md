# Andamento por frente

Cada agente registra aqui o que fez, em um arquivo próprio (`entrevista.md`, `site.md`, `skill.md`, `google.md`, `instagram.md`, `operacao.md`). Assim ninguém disputa o mesmo arquivo. As frentes estão descritas em `../frentes.md`.

Formato de cada registro:

```
## <data>
- Feito: o que foi entregue, com o caminho do arquivo
- Pendências: o que falta e quem resolve (Aline, Vinícius ou outra frente)
- Pedidos para outras frentes: o que precisa que outra frente faça
```
